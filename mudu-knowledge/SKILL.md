# 答案 · 解析 · 知识点（第 4 步）

**输入**：原卷 + 参考答案 + `03_types/types.json`。
**输出**：`04_knowledge/knowledge.json`

```json
{"AH-2022-021": {"answer": "A", "explanation": "考查动词……",
                 "knowledge": ["动词辨析"],
                 "subs": [{"number": 21, "knowledge": ["动词辨析"]}]}}
```

## 4.1 答案与解析

- **答案**：原卷「参考答案」是唯一来源；只写内容，不加「答案：」；题组写进每个子题，组级用 `; ` 拼接。
- **解析**：原卷给了就写，去掉「【解析】」；**没给就留空**，不编造、不写占位语。
- **文章大意**：原卷有【文章大意】才写。

## 4.2 七维度打标

主题 / 语篇体裁 / 阅读技能 / 语法 / 词汇 / 语用 / 语音。一题 1–3 个，**同维度只挂一个**。

| 题型 | 该挂 | 禁挂 |
| --- | --- | --- |
| 完形填空 | 语篇体裁 + 主题（+ 句意理解） | 语法、词汇辨析 |
| 单项填空 | 语法点 / 辨析 / 搭配 / 情景交际 | 主题、语篇体裁 |
| 听力各题型 | 语篇体裁 + 主题 | 语法 |
| 阅读理解 | 阅读技能 + 语篇体裁 + 主题 | 语法、词汇辨析 |
| 补全对话 | 语用 + 语篇体裁 + 主题 | 语法（填写句子类除外） |
| 单词拼写 | 词汇辨析/<词性> | 词汇父节点 |

## 4.3 两条硬要求

1. **词分类是详细匹配**：`词汇`、`词汇辨析`、`语篇体裁/记叙文`、`语音/基本读音` 都是父节点，
   必须下钻到叶子（名词辨析/动词辨析…、故事/人物传记…、字母在单词中的基本读音…）。
2. **单词拼写按答案词性倒推**：名词→名词辨析、动词→动词辨析、形容词→形容词辨析、副词→副词辨析；
   需变形再加 `名词的数`／`动词的基本形式`，需派生加 `构词法`。

## 4.4 子题

- 组级 = 该组考的能力；子题 = 各自精确考点。
- **每个阅读小题必须有一个 `阅读技能/*`**，按设问判（best title→最佳标题、infer→推理判断）。

## 4.5 工具

```bash
python scripts/find_kp.py 被动语态                       # 查节点，别凭记忆写路径
python scripts/apply_type_tags.py --batch b.json --out b2.json   # 按题型补默认
python scripts/fill_subtags.py --ids AH-2022 --list      # 找空子题
python scripts/spell_pos.py --list                       # 拼写题列答案
python scripts/check_tags.py --ids AH-2022               # 体检
```

## 验收

- [ ] 每题都有 `answer`，与答案卷逐题一致（不一致数必须 0）
- [ ] `explanation` 无前缀、无编造
- [ ] `check_tags.py` 退出码 0（无空标签/禁标/未下钻）
- [ ] 每个阅读子题都有 `阅读技能/*`
