# 知识点打标标准

## 三份文件各管什么

| 文件 | 作用 |
| --- | --- |
| `knowledge-catalog-1.0.md` | 目录原文（人读，带层级与说明） |
| `knowledge-catalog.json` | 514 个节点的 `id / path / name`，打标时解析 ID 用 |
| `type-knowledge-map.json` | 26 个题型 → 默认标签 + 需逐题判断的提示 |
| `type-knowledge-map.md` | 上面那份的可读版 |

**查节点不要凭记忆**：

```bash
python scripts/find_kp.py 被动语态
python scripts/find_kp.py 细节 --branch 阅读技能
python scripts/find_kp.py --list-branches
```

**按题型自动打底**：

```bash
python scripts/apply_type_tags.py --batch batch.json --out batch_tagged.json
```

只补「当前没有知识点」的单元；题目特有的考点（单项填空的具体语法点、完形的篇章主题）脚本只打印提示，仍需逐题判断。

> 26 个主类逐条的对照表见 `type-knowledge-map.md`（与 `题库筛选与检索框架1.1-含知识点.xlsx`、`桌面/题型-知识点对照表.xlsx` 同源）。
> 本文讲的是**判断原则**，那几份是**落地结果**；改一处要同步其余。

知识点不是「这题出现了什么词」，而是**这题在考什么能力**。同一道题可以挂多个知识点（语法 + 辨析 + 搭配），
但每个标签都要能回答「如果把这题拆开，它训练的是哪一项」。

## 七个维度

| 维度 | 目录分支 | 回答的问题 |
| --- | --- | --- |
| 主题 | `主题/` | 这篇材料在说什么话题（人与自我 / 人与社会 / 人与自然 三级叶） |
| 语篇体裁 | `语篇体裁/` | 这是什么文体（故事 / 说明文 / 信件 / 广告 / 对话…） |
| 阅读技能 | `阅读技能/` | 设问在考哪种读法（细节 / 推理 / 主旨 / 词义 / 标题 / 出处…） |
| 语法 | `语法/` | 具体语法点，尽量到叶 |
| 词汇 | `词汇/` | 辨析（词性）或固定搭配 |
| 语用 | `语用/` | 情景交际、谚语习语 |
| 语音 | `语音/` | 辨音、重音、语调 |

## 按题型的判定规则

| 题型 | 主标签（必打） | 可叠加 | **不要打** |
| --- | --- | --- | --- |
| 听力·关键词语选择 | `语音/基本读音` | `词汇/词汇辨析`（选项是音近/形近词时） | 语法、主题 |
| 听力·短对话 / 长对话 | `主题/<话题>` | `语篇体裁/日常口语/日常对话` | 语法、词汇辨析 |
| 听力·短文理解 | `主题/<话题>` | `语篇体裁/日常口语/独白` | 语法 |
| 听力·信息转换 | `主题/<话题>` | `语篇体裁/日常口语/独白` | 语法、拼写 |
| 单项填空 | `语法/<具体考点>` 或 `词汇/词汇辨析/<词性>` 或 `语用/情景交际` | 可同时挂语法 + 辨析 + 搭配（最多 3 个） | 主题、语篇体裁 |
| **完形填空** | `语篇体裁/<文体>` + `主题/<话题>` | 需要时加 `阅读技能/句意理解` | **语法、词汇辨析** |
| 补全对话 | `语用/情景交际` | `语篇体裁/日常口语/日常对话`、`主题/<话题>` | 语法 |
| 阅读理解 | `阅读技能/<设问类型>` | `语篇体裁/<文体>`、`主题/<话题>` | 语法、词汇辨析 |
| 任务型阅读 | `阅读技能/细节理解` 或 `主旨大意` | `语篇体裁/<文体>` | 语法 |
| 单词拼写 | `词汇`（拼写/词形层面） | 有明确构词依据时加 `词汇/构词法/*` | 语法、阅读技能 |
| 书面表达 | `语篇体裁/<应用文体>` | `主题/<话题>` | 语法 |

## 为什么完形不挂语法和辨析

完形填空的每个空都是**在篇章里做选择**：四个选项单看都可能成立，靠上下文决定。它训练的是
「读篇章、抓主题、还原语义」，不是「背语法规则」或「辨词义」。

挂了 `词汇辨析/动词辨析` 会把完形混进「单项填空类」的检索结果，编辑按「辨析」筛题时会捞出一堆完形，
按「完形」筛题时又看不到语法干扰项——**分类就失真了**。

同理，单项填空不要挂主题：它没有篇章，谈不上话题。

## 多标签的边界

- 一道题 1–3 个标签，超过 3 个基本说明没想清楚主考什么。
- 同一维度只挂一个：一题不会同时「主考细节理解」又「主考主旨大意」。
- 跨维度可以叠加：语法题同时考搭配（`语法/谓语动词的时态和语态/一般过去时` + `词汇/短语与固定搭配/动词短语`）。
- 题组的组级知识点 = 各子题考点的并集；子题各自保留精确考点（`subquestions[].knowledge`）。

## 自检

- [ ] 每个单元至少 1 个知识点，题组的每个子题都有
- [ ] 完形里没有出现 `语法/` 或 `词汇/词汇辨析/`
- [ ] 单项填空里没有出现 `主题/` 或 `语篇体裁/`
- [ ] 阅读题的知识点里有一个 `阅读技能/*`
- [ ] 标签都来自当前启用目录（路径能解析成 ID）

## 大主题必须下钻到叶子

标了「词汇」「语篇体裁/记叙文」「语音/基本读音」这类父节点，等于只做了初步判断，**还要往下找具体节点**：

| 父节点 | 常见叶子 | 判断依据 |
| --- | --- | --- |
| 词汇/词汇辨析 | 名词辨析、动词辨析、形容词辨析、副词辨析 | 看四个选项的词性 |
| 词汇/短语与固定搭配 | 动词短语、介词短语 | 选项是短语时 |
| 词汇/构词法 | 派生法、合成法、转化法 | 答案需要前后缀或词性转换 |
| 语篇体裁/记叙文 | 故事、人物传记、童话、简版小说 | 叙事 / 记人 / 寓言 |
| 语篇体裁/说明文 | 介绍类短文、事理阐释 | 介绍事物 / 解释道理 |
| 语篇体裁/日常口语 | 日常对话、独白 | 对话 / 独白 |
| 语篇体裁/应用文 | 私人信件、通知、活动计划、问卷、广告 | 看格式与用途 |
| 语音/基本读音 | 字母在单词中的基本读音、常见元音字母组合读音… | 辨音题多落在「字母在单词中的基本读音」 |
| 语法/…/被动语态 | 一般现在时/一般过去时/一般将来时的被动语态 | 看助动词形式 |

**父节点下没有合适子节点时**，不要硬套兄弟节点，也不要建节点：提交
`POST /api/catalog/knowledge-proposals` 由人工批准。例：单词拼写题只能挂「词汇」，
已提交「拼写与词形」建议（KPP-5bce69d81f544defbfea）。
