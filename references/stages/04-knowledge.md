# 答案与知识点（04-knowledge）

**输入**：原卷 + 参考答案 + `03_types/types.json`。
**输出**：`04_knowledge/knowledge.json`

```json
{"AH-2022-021": {"answer": "A", "explanation": "考查动词……",
                 "knowledge": ["动词辨析"],
                 "subs": [{"number": 21, "knowledge": ["动词辨析"]}]}}
```

## 4.1 答案与解析

- **答案**：原卷「参考答案」是唯一来源；只写内容，不加「答案：」；题组写进每个子题，组级用 `; ` 拼接。
- **解析**：原卷给了就写，去掉「【解析】」；**没给就留空**，不编造、不写占位语。
- **文章大意**：原卷有【文章大意】才写。

## 4.2 打标维度（按《题型-知识点标签对照表1.0》）

每个题型只打它规定的维度，见 `references/type-knowledge-map.md`。

**显示规则：括号里的才是要显示的标签；维度根节点（主题/词汇/语法/语音/语用/语篇体裁/阅读技能）不显示。**

| 题型 | 应显示 |
| --- | --- |
| 听力短对话理解 | 主题、设题角度（听力） |
| 听力长对话理解 | 主题、设题角度（听力） |
| 听力短文理解 | 语篇体裁、主题、设题角度（听力） |
| 听力信息转换 | 语篇体裁、主题、设题角度（听力）、答案考点 |
| 听力判断 | 语篇体裁、主题、设题角度（听力） |
| 听力排序 | 语篇体裁、主题、设题角度（听力） |
| 听力问答 | 语篇体裁、主题、设题角度（听力） |
| 听力其他 | 语篇体裁、主题、设题角度（听力） |
| 语音题 | 语音 |
| 单项填空 | 词汇、语法、语音、语用、答案考点 |
| 完形填空 | 语篇体裁、主题 |
| 语法选择 | 语篇体裁、主题 |
| 阅读理解 | 语篇体裁、主题、设题角度（阅读） |
| 任务型阅读 | 语篇体裁、主题、设题角度（阅读） |
| 教材语篇填空 | 语篇体裁、主题、词汇、语法、答案考点 |
| 短文填空 | 语篇体裁、主题、词汇、语法、答案考点 |
| 选词填空 | 语篇体裁、主题、词汇、语法、答案考点 |
| 补全对话 | 语篇体裁、主题、语用 |
| 单词拼写 | 词汇、语法、语音、答案考点 |

| 情景运用 | 词汇、语法、语用 |
| 翻译 | 词汇、语法、语用 |
| 改错 | 词汇、语法 |
| 读写综合 | 语篇体裁、主题、设题角度（阅读） |
| 书面表达 | 语篇体裁、主题 |
| 其他 | 语篇体裁、主题、阅读技能、词汇、语法、语音、语用、答案考点 |
| 听力关键词语选择 | 语音、词汇、答案考点 |

要点：

- 主题写「一级主题 + 最后一级」两段，中间层不写。
- 语篇体裁、词汇、语法、语音写根以下各级（如「记叙文 / 故事」「词汇辨析 / 动词辨析」）。
- 语用只写叶子。
- 阅读类设题角度写「阅读技能」叶子；听力暂无对应分支，先不落标。
- 填空、拼写、完成句子、选词：另加**答案考点**（该空考的词汇/语法叶子）。

## 4.4 子题

- 组级 = 该组考的能力；子题 = 各自精确考点。
- **每个阅读小题必须有一个 `阅读技能/*`**，按设问判（best title→最佳标题、infer→推理判断）。

## 4.5 工具

```bash
python scripts/find_kp.py 被动语态                       # 查节点，别凭记忆写路径
python scripts/apply_type_tags.py --batch b.json --out b2.json   # 按题型补默认
python scripts/fill_subtags.py --ids AH-2022 --list      # 找空子题
python scripts/spell_pos.py --list                       # 拼写题列答案
python scripts/check_tags.py --ids AH-2022               # 体检
```

## 验收

- [ ] 每题都有 `answer`，与答案卷逐题一致（不一致数必须 0）
- [ ] `explanation` 无前缀、无编造
- [ ] `check_tags.py` 退出码 0（无空标签/禁标/未下钻）
- [ ] 每个阅读子题都有 `阅读技能/*`
