# 题型与子类（03-type-map）

**输入**：`01_source/structure.json` + 原卷。
**输出**：`03_types/types.json`

```json
{"AH-2022-001": {"type": "听力短对话理解", "subtypes": ["选图片"]},
 "AH-2022-021": {"type": "单项填空", "subtypes": ["四个选项"]}}
```

## 3.1 两级匹配

1. **主类**：只能取 `filter-framework.json` 的 27 个主类（`http://127.0.0.1:8089/filter-framework.json`）。
2. **子类**：在该主类的 `subtypes` 里逐条比对判定线索，见 `references/type-subtypes.md`。

子类决定筛选能不能命中：**漏写 `subtypes`，这题在按子类筛选时会消失**。

| 线索 | 主类 | 子类 |
| --- | --- | --- |
| 选项是 A./B./C. 空壳 + 配图 | 听力短对话理解 | 选图片 |
| 一段对话带 2 / 3 个小题 | 听力长对话理解 | 选择2题 / 选择3题 |
| 短文 5 个小题 | 听力短文理解 | （无子类） |
| 听短文填表格 | 听力信息转换 | （无子类） |
| 4 个选项的单句 | 单项填空 | 四个选项 |
| 一篇短文 10 空 | 完形填空 | 10空 |
| 七选五对话 | 补全对话 | 7选5 |
| 一篇 3/4/5 个选择题 | 阅读理解 | 选择3题/选择4题/选择5题 |
| 七选五补全短文 | 阅读理解 | 阅读回填 |
| 限词数回答 | 任务型阅读 | 阅读问答 |
| 首字母 + 汉语 | 单词拼写 | 汉语及首字母 |
| 中文要点 + 80 词 | 书面表达 | 列中文要点 |

## 3.2 不标准题型怎么办

1. 大题标题找线索词 → 2. 子类表逐条比对 → 3. 命中就选 → 4. 主类有「其他」就选「其他」并注明理由 →
5. 连主类都对不上 → **暂停该批**，报候选与依据给人工。

**禁止**：新增/改名/合并主类或子类。目录没有完全对应的形态（如安徽「关键词语选择」）选语义最近的
（`听力其他`），并在交接单登记。

## 验收

- [ ] 每题 `type` 在 27 主类内
- [ ] 有子类的主类都填了 `subtypes`，且值在框架里
- [ ] 无法匹配的已列出，没有硬塞
