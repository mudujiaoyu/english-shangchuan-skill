# 听力切分（02-audio）

**输入**：整卷 mp3 + （可选）听力稿。
**输出**：`02_audio/`：`li-01.mp3 …` + `audio_map.json`。

```json
{"AH-2022-001": {"file": "li-01.mp3", "duration": 25.5, "covers": [1]},
 "AH-2022-006": {"file": "li-06.mp3", "duration": 64.6, "covers": [6, 7]}}
```

**段数 = 结构清单里的听力单元数，不是题数。**

## 2.1 三步切法

1. **分层**：`ffmpeg -af silencedetect=noise=-35dB:d=1.2` 拿静音表，看时长分层（题间 8–15s vs 题内 1–2s）。
2. **找锚点**：优先用录音里念出的题号（"Number 7"/"Seven"），其次用长静音中点。
3. **回读校验**：每段切 20–30 秒转写，与听力稿逐行比对，**必须全中**；不中就调锚点重切。

```bash
python scripts/cut_audio.py --audio 听力.mp3 --report          # 分层
python scripts/cut_audio.py --audio 听力.mp3 --transcribe      # 转写找锚点
python scripts/cut_audio.py --audio 听力.mp3 --anchors 40.1,66.6 --ends ... --out 02_audio/ \
    --verify --verify-seconds 20                               # 只回读每段前 20 秒
```

**`--verify-seconds` 是省时间的关键**：校验只判「每段首句对不对」，整段转写纯属浪费。
2025 卷整段校验要 11 分钟，2026 卷改成 20 秒后同样的 9 段切分+校验只要 **9 秒**。
长段（短文 120s、信息转换 90s）尤其明显。

**锚点可以直接从静音表推**，不必先跑全卷转写：题间静音有稳定档位（8–17s，大题之间 27–29s），
只看「该段起点之后的语音是英文还是中文题头」就够了。做法：
1. `--report` 拿静音表与档位；
2. 长静音对（结束点=起点候选）先按档位切出候选段；
3. 对可疑边界（大题交界）切 10–15 秒单独转写，确认是英文正文还是中文题头；
4. 定稿后 `--verify --verify-seconds 12~20` 逐段回读首句。

2026 实测：全流程（分层 + 2 次边界探针 + 切分 + 9 段回读）约 40 秒；
其中「中文题头」是最容易漏的——中文播报会占 15–20 秒，直接按静音中点切会把播报吞进上一段或当成下一段开头。

## 2.2 卷首试音必须切掉

录音开头常有试音（1kHz 测试音、反复 "Thank you."、中文设备说明），不属于任何一题。

- `--transcribe` 看第一条正文开口时间 → `--intro-end 29.1` 丢弃之前全部；
- `--trim-intro` 只吸掉首段前的死气，**不认识试音**。

## 2.3 听力材料（录音稿）

答案册末尾通常有「附:听力录音材料」，是官方录音稿，按 Ⅰ/Ⅱ/Ⅲ/Ⅳ 分节：

```bash
python scripts/02-audio/extract_script.py --docx 答案.docx --list
python scripts/02-audio/extract_script.py --docx 答案.docx --year 2022 --out ts.json
```

产出 `short[5] / long[2] / passage / conversion`，直接写入对应组题的 `material`：

| 单元 | 用哪段 |
| --- | --- |
| 长对话（6~7、8~10） | `long[0]`、`long[1]` |
| 短文理解 | `passage` |
| 信息转换 | `conversion`（可拼在表格标题后） |

短对话是独立题不是组题，默认不写 material（避免题卡上出现录音稿）。

## 2.4 坑

- **转写时间戳不可靠**（试音是单音，VAD 会切出几十个碎片）：用静音表定骨架，转写只用来找题号。
- 同一题读两遍，按静音切会把两遍劈开 → 切点要落在题间的长静音里。
- 编码 `-ac 1 -ar 22050 -b:a 48k`；同类单元时长应接近，明显偏长说明吞了下一题。

## 验收

- [ ] 段数 = 听力单元数
- [ ] 每段首句与听力稿一致（或仅个别因音质存疑）
- [ ] 试音不在 li-01 里
- [ ] `audio_map.json` 覆盖全部听力单元
