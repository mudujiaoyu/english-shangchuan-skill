# 同步练习册（课时作业）录题配方

按它逐条填，不用每次重新推导。适用于《课时A计划》这类「每课时若干大题、题型重复」的教辅。

**总规则见 `references/constraints.md`**；本文件只回答「这个题型该建成什么样」。

## 一、先定粒度（错一次就要人工删草稿）

判据是**原卷这个大题是不是一个整体**：

| 原卷形态 | 粒度 | 理由 |
| --- | --- | --- |
| 每小句各自独立、只有一句提示（单词拼写、完成句子、单项填空、语音辨音） | **逐题独立** | 拆开后互不影响 |
| 一个语篇 / 一段对话 / 一张表 / 一个方框（完形、阅读、任务型、补全对话、选词、短文、教材语篇） | **整题组** | 拆开就丢上下文 |
| 一个任务下多空且「每词限用一次」（选词填空、音标分类） | **整题组** | 空与空互相牵制 |

> ⚠️ `unit_kind` 建批时定死，`PATCH` 改不了、草稿还得人工删。**接新册别先问这一条。**

## 二、逐题型配方

### 单词拼写（`001–099`，逐题）

| 项 | 写法 |
| --- | --- |
| `type` / `subtypes` | `单词拼写` / `汉语及首字母`（每题自带首字母+汉语）、`汉语提示`（只有汉语）、`适当形式`（给词原形要求变形） |
| `stem` | 首字母题 `The loong … in a______ (古代的) China.`（**首字母紧贴空档**）；汉语提示题 `My sister has long hair.It feels just like ______ (丝绸).` |
| `answer` | 单词原形；可数名词给原形，题目要求复数时答案写复数 |
| `knowledge` | 答案词的词性：`词汇/词汇辨析/名词辨析|动词辨析|形容词辨析|副词辨析`；需变形加 `语法/名词/名词的数/…`；需派生加 `词汇/构词法/派生法（前缀、后缀）` |
| 坑 | 主题维度**不允许**（C8/C9） |

### 完成句子（`101–199`，逐题）

| 项 | 写法 |
| --- | --- |
| `type` / `subtypes` | `完成句子` / `汉语提示`（译成英文）、`改写句子`（句型转换） |
| `stem` | **两行**：第 1 行中文提示，第 2 行英文不完整句（D14）<br>`一个愉快的假期过后，李老师回去工作了。\nMiss Li ______ work after a pleasant holiday.` |
| 句型转换 | 第 1 行原文 + 括号要求：`Jim told me something interesting.（改为否定句）`，第 2 行带空档的改写句 |
| `answer` | 一个空就写答案；**多空用 `;` 分隔**：`didn’t go anywhere;stayed at home` |
| `knowledge` | `词汇/短语与固定搭配/…`、`语法/谓语动词的时态和语态/…`、`语法/句子的种类/疑问句/…` |
| 坑 | 主题维度**不允许**；不要只放中文（学生看不到要填的句子框架） |

### 单项填空（`501–599`，逐题）

| 项 | 写法 |
| --- | --- |
| `type` / `subtypes` | `单项填空` / `四个选项`（三个选项时才用 `三个选项`） |
| `stem` | 题干原样；对话式保留 `—` 与换行 |
| `options` | `["A.…","B.…","C.…","D.…"]`，**保留 `A.` 前缀** |
| `knowledge` | 按考点：`词汇/词汇辨析/…`、`语法/…`、`语用/情景交际` |
| 坑 | 原卷个别题的空档只有一个半角空格，**要补 `______`**（B3） |

### 补全对话（`201–299`，整题组）

| 项 | 写法 |
| --- | --- |
| `type` / `subtypes` | `补全对话` / `7选5`（5 空 7 选项） |
| `material` | 整段对话，空位标 `1.______`、`2.______`… |
| `options` | 单元级 `options` 放 A–G 七项 |
| `answer` | `A; E; D; F; C` |
| 子题 | `stem` 用 `______`（材料已有编号，D3）；`answer` 各一字母 |
| `knowledge` | `语篇体裁/日常口语/日常对话` + `语用/情景交际` |

### 语音题（`301–499`，辨音逐题 / 音标分类整题组）

| 形态 | 写法 |
| --- | --- |
| 辨音（选出读音不同的一项） | **逐题**；`stem` = `选出下列每组单词中画线部分读音不同的一项。`；`options` = 四个单词；`knowledge` = `语音/基本读音/字母在单词中的基本读音` |
| 音标分类（方框词按音标归类） | **整题组**；`material` = 词表；子题 `stem` = `/ɪ/: ______`（空位带内容，D5）；答案 = 该音标的词，逗号分隔 |

- `subtypes` 留空（框架里就没有）
- **语音题不是听力**：难度按题型基准给分，不要留「待定」（C7）

### 完形填空（`601–699`，整题组）

| 项 | 写法 |
| --- | --- |
| `subtypes` | `10空`（或 `5空` / `15空` / `其他空数`） |
| `material` | 整篇短文，空位标 `__1__`…`__10__` |
| 单元 `options` | **留空**（选项挂子题） |
| 子题 `stem` | **写题号** `1.`、`2.`…（前端剥掉重复题号后显示「1. + 四个选项」，D12） |
| 子题 `options` | 四个，`A.`…`D.` 前缀 |
| `knowledge` | 单元：`语篇体裁/记叙文/故事` + 主题；子题：按该空答案词性给 `词汇/词汇辨析/…` |
| 坑 | 完形**只允许「语篇体裁/主题」**两个维度，别挂设题角度或词汇语法（C9） |

### 阅读理解（`701–799`，整题组）

| 项 | 写法 |
| --- | --- |
| `subtypes` | `选择3题` / `选择4题` / `选择5题` / `阅读判断` / `阅读匹配` / `阅读排序` / `阅读回填` |
| `material` | 整篇；小标题用空行分隔 |
| 子题 `stem` | **照写设问**（阅读的设问就是子题内容，不适用 D3） |
| 子题 `options` | 四个（判断/匹配类可为空） |
| `knowledge` | `语篇体裁/…` + 主题 + `设题角度/阅读/*`（细节理解、推理判断、主旨大意、代词指代、猜测词义、图片理解、细节多选…） |
| `article_summary` | 从答案册【文章大意】摘；源卷没有则留空 |
| 图 | 全篇材料图挂单元 `placement=question`；**某一小题的配图挂该子题**（D13/C13） |

### 任务型阅读（`801–899`，整题组）

| 项 | 写法 |
| --- | --- |
| `subtypes` | `阅读问答`（问句作答）、`阅读填表`、`信息摘录`、`补全句子`、`补全短文`、`阅读综合` |
| `material` | 整篇 |
| 子题 `stem` | 设问原样，**保留「（不超过5个词）」这类字数限制** |
| 子题 `answer` | 答案句；多解用 `/`；**去掉「（言之有理即可）」中文括注**，放解释里（F4） |
| `knowledge` | `设题角度/阅读/细节理解` + 开放设问加 `设题角度/阅读/开放性设问` |

### 选词填空（`901–999`，整题组）

| 项 | 写法 |
| --- | --- |
| `subtypes` | `多句`（每空一句，最常见）、`短文`、`单句` |
| `material` | 方框词表 + 带编号的句子，空位 `__1__`… |
| 子题 `stem` | `______`（材料已有编号） |
| 子题 `answer` | 变形后的形式（`bored`、`surprised`、`worries`） |
| `knowledge` | `词汇/构词法/派生法（前缀、后缀）`（需变形时）+ 具体语法叶子 |
| 坑 | 子题**没有选项**，`check_text` 不该按完形要求 4 选项（C12） |

### 短文填空（`1001–1099`，整题组）

| 项 | 写法 |
| --- | --- |
| `subtypes` | 留空（框架里没有） |
| `material` | 整篇，空位 `__1__(face)`、`__4__i______`、`__7__p______(平静)` |
| 子题 `stem` | `______` |
| `knowledge` | `词汇/构词法/派生法…` + `阅读技能/句意理解`（用 `设题角度/阅读/句意理解` 会越界，只用词汇/语法/主题） |

### 教材语篇填空（`1101–1199`，整题组）

| 项 | 写法 |
| --- | --- |
| `subtypes` | `人教版` |
| `material` | 平铺文本兜底 |
| `materialBlocks` | **原卷是表格时必须还原**：`type=table` + `variant=""`，日期/类别列用 `rowspan` 合并、标题用 `colspan`（E5–E8） |
| 子题 `stem` | `______` |
| `knowledge` | `语篇体裁/日记` + `词汇/构词法/派生法…` |

### 翻译 / 佳句仿写（`1201–1299`，逐题）

| 项 | 写法 |
| --- | --- |
| `subtypes` | `汉翻英` |
| `stem` | 例句 + 汉语要求（仿写要给出范例句式） |
| `knowledge` | `词汇/短语与固定搭配/…` + 涉及语法（如 `语法/动词的非谓语形式/…`）；主题维度不允许 |

## 三、必跑的四道闸门

```bash
S=~/.agents/skills/mudu-question-upload/scripts
python $S/05-meta/assign_meta.py    --batch batch.json --out batch_meta.json --report
python $S/04-knowledge/check_tags.py --batch batch_meta.json      # 维度越界
python $S/06-upload/check_text.py    --batch batch_meta.json      # 空档/引号/破折号
python $S/06-upload/check_structure.py --batch batch_meta.json    # 粒度与子题
python $S/06-upload/run_upload.py    --batch batch_meta.json --media-dir media/ --media-name <批次名>
```

`run_upload.py` 已把前四道并进本机并行体检；单独跑用于定位。

## 四、常见返工点（按出现频次）

| 返工点 | 症状 | 对应约束 |
| --- | --- | --- |
| 全角空格空档 | 页面看不见横线 | B2 |
| 首字母与空档之间多空格 | `c ______` 被当成两个词 | B4 |
| 完成句子只放中文 | 学生看不到句子框架 | D9 |
| 完成句子拼成一行 | 中文英文挤一起 | D14/D15 |
| 组题子题写「第N空」 | 与材料编号重复 | D3 |
| 完形子题写 `______` | 多一个空档，不像试卷 | D12 |
| 小题配图挂单元 | 图跑到材料区 | D13 |
| 表格式材料压成文本 | 三栏关系丢失 | E5 |
| 填空类被要求 4 选项 | 假阳性 | C12 |
| 知识点挂父节点 / 跨维度 | 越界或非叶子 | C9/A15 |
