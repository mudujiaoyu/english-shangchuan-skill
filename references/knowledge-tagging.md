# 知识点打标

依据：`references/type-knowledge-map.json`（源表《题型-知识点标签对照表1.0.xlsx》）+ `knowledge-catalog.json`（514 个节点）。

## 一、显示规则（优先级最高）

**括号里的是要显示的多级子标签；维度根节点本身不显示。**

| 显示层级 | 含义 | 例 |
| --- | --- | --- |
| `叶子`（主题） | 主题只写**最后一级叶子**；一级主题（人与自我/人与社会/人与自然）是父节点，不落库 | 信息安全、兴趣爱好 |
| `根以下各级` | 语篇体裁、词汇、语法、语音：根以下的各级标题 | 记叙文 / 故事；词汇辨析 / 动词辨析 |
| `叶子` | 语用只写叶子 | 情景交际、谚语/习语 |
| 阅读子项 | 设题角度用 `设题角度/阅读` 叶子 | 细节理解、推理判断、最佳标题 |

**为什么主题不写两级**：一级主题底下还有子节点，`check_tags.py` 会把它判成「停在父节点」直接失败；
库内 250 个安徽单元的既有数据也是叶子口径。对照表写的「一级+叶子」按「叶子落地」执行，
一级主题只出现在交接单的说明文字里。

**绝对不要**把 `主题`、`词汇`、`语法`、`语音`、`语用`、`语篇体裁`、`设题角度` 这些根节点写进标签。
`check_tags.py` 会把根节点判为「非叶子」并报错。

## 三、按题型执行

- **听力**：主题（叶子）。短文、信息转换、判断、排序、问答额外要语篇体裁。
  设题角度按目录 1.1 的 `设题角度/听力/*` 落标（细节理解/推理判断/人物关系/地点推断/主旨大意）。
- **单项填空**：词汇、语法、语音各取根以下各级；语用取叶子；再加答案考点。
- **完形 / 语法选择**：只写语篇体裁 + 主题，不写语法、不写词汇辨析。
  子题（每个空）可以挂该空考的词汇叶子，组级不挂——库内 2020 卷即此做法。
- **阅读 / 任务型 / 读写综合**：语篇体裁 + 主题 + `设题角度/阅读/*`。
  组级的设题角度写**组内出现过的全部角度**（按次数排序），子题各写自己那一个；
  子题**不要**挂语篇体裁（体裁属于整组材料），挂了会让按体裁筛选命中整组却指错。
- **阅读题的图片**：材料图挂单元 `attachments`（`placement:"question"`）；某道小题的选项图挂
  **子题** `attachments`（`placement:"option"` + `optionKey`）。挂到单元上的选项图前端不渲染，见 06-upload.md 6.2b。
- **教材语篇填空 / 短文填空 / 选词填空**：语篇体裁 + 主题 + 词汇 + 语法 + 答案考点。
- **补全对话**：语篇体裁 + 主题 + 语用。
- **单词拼写**：词汇 + 语法 + 语音 + 答案考点。
- **完成句子**：词汇 + 语法 + 答案考点。
- **情景运用 / 翻译**：词汇 + 语法 + 语用。
- **改错**：词汇 + 语法。
- **书面表达**：语篇体裁 + 主题。
- **其他**：按实际材料判语篇体裁、主题；阅读类任务加 `设题角度/阅读/*`；其余按内容。

## 四、答案考点怎么写

不是独立维度：写该题或该空实际考到的**词汇或语法叶子**。

- 单词拼写：名词→`名词辨析`；动词→`动词辨析`；需变形再加 `名词的数` / `动词的基本形式`；需派生加 `构词法/派生法（前缀、后缀）`。
- 选词填空 / 完成句子：写出该空的搭配或语法点叶子（如 `固定搭配`、`一般过去时`）。
- 一道题可能有多处考点 → 多个叶子并列，仍遵守「同维度只挂一个」的例外：不同维度可并列。

## 四之二、设题角度分听力/阅读（目录 1.1）

目录 1.1 把原来的「阅读技能」并进 `设题角度`，并新增 `设题角度/听力`：

| 分支 | 节点 |
| --- | --- |
| `设题角度/听力` | 细节理解、推理判断、人物关系、地点推断、主旨大意 |
| `设题角度/阅读` | 细节理解、推理判断、主旨大意、最佳标题、代词指代、文章出处、文本类型、篇章结构、写作手法、猜测词义、词义理解、句意理解、观点态度、单词/句子回填、图片理解、句子排序、推断文章后续发展、推断人物情绪变化、细节多选、文章脉络、跨学科设问、开放性设问 |

- **听力类题型**（短对话、长对话、短文、信息转换、判断、排序、问答、其他）→ 打 `设题角度/听力/*`
- **阅读类题型**（阅读理解、任务型阅读、读写综合）→ 打 `设题角度/阅读/*`
- 「细节理解」在两边各有一个，**必须带上级**，`check_tags.py` 会拦下不带 scope 的写法。

### 设题角度怎么定（听力）

| 设问特征 | 设题角度 |
| --- | --- |
| where / which place | 地点推断 |
| who / whose / whom / relationship | 人物关系 |
| why / what can we learn / suggest / infer / mean / think of | 推理判断 |
| main idea / mainly / best title / topic | 主旨大意 |
| 其余（含信息转换空题干、判断、排序） | 细节理解 |

python scripts/04-knowledge/assign_angle.py --ids AH-2022          # 干跑

组题（长对话/短文/信息转换）**保留组内出现过的所有角度**，按出现次数排序，例如一组长对话含
「When / Where / What do you think of」，组级就同时带 细节理解、地点推断、推理判断——
这样按任一角度筛选都能命中该组。子题各自的精确角度记在子题 `knowledge` 里。

`听力关键词语选择` 不适用（对照表不含设题角度）。

## 四之三、听力关键词语选择

27 类主类之一（框架 1.1 已收录），打标：`语音/基本读音/<子项>` + `词汇/词汇辨析/<词性>` +答案考点。
不再挂在「听力其他」下。

## 五、多标签原则

1. 一题通常 2–4 个标签，**同一维度最多一个**（主题只占一个叶子）。
2. 组级标签写整段材料（体裁 + 主题）；子题标签写各自考点（`设题角度/阅读` 叶子）。
3. 拿不准就不加，不要凑标签；加了错标签比没加更难查。

## 六、校验

```bash
python scripts/04-knowledge/find_kp.py 推理判断     # 查节点是否存在
python scripts/04-knowledge/find_kp.py --list-branches
python scripts/04-knowledge/check_tags.py --ids AH-2022
python scripts/04-knowledge/check_tags.py --batch 06_batch/b.json   # 上传前查
python scripts/04-knowledge/fill_subtags.py --ids AH-2022 --list   # 找空子题
```

`check_tags.py` 的判定口径：

| 项 | 含义 | 默认是否失败 |
| --- | --- | --- |
| 空标签 | 没有知识点 | 失败 |
| 非叶子 | 停在父节点（含维度根节点） | 失败 |
| 禁标维度 | 旧规则里的硬禁止（保留兼容） | 失败 |
| 越界维度 | 不在该题型「可考范围」内（对照表派生） | 只报告，`--strict` 才失败 |

「可考范围」来自对照表：例如听力短对话只有 主题、设题角度，打了 `语篇体裁/日常口语` 就是越界；
完形只有 语篇体裁、主题，打了 `阅读技能/句意理解` 也是越界。历史数据按旧规则打过标，
所以默认只报告；新录的题建议用 `--strict` 卡住。
