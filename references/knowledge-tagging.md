# 知识点打标

依据：`references/type-knowledge-map.json`（源表《题型-知识点标签对照表1.0.xlsx》）+ `knowledge-catalog.json`（514 个节点）。

## 一、显示规则（优先级最高）

**括号里的是要显示的多级子标签；维度根节点本身不显示。**

| 显示层级 | 含义 | 例 |
| --- | --- | --- |
| `一级+叶子` | 主题写两段：一级主题 + 最后一级 | 人与社会 / 信息安全 |
| `根以下各级` | 语篇体裁、词汇、语法、语音：根以下的各级标题 | 记叙文 / 故事；词汇辨析 / 动词辨析 |
| `叶子` | 语用只写叶子 | 情景交际、谚语/习语 |
| 阅读子项 | 设题角度用「阅读技能」叶子 | 细节理解、推理判断、主旨大意 |

**绝对不要**把 `主题`、`词汇`、`语法`、`语音`、`语用`、`语篇体裁`、`阅读技能` 这些根节点写进标签。
`check_tags.py` 会把根节点判为「非叶子」并报错。

## 三、按题型执行

- **听力**：主题（一级+叶子）。短文、信息转换、判断、排序、问答额外要语篇体裁。
  设题角度对应「听力子项」，当前目录只有「阅读技能」分支，**暂不落标**，等目录补充。
- **单项填空**：词汇、语法、语音各取根以下各级；语用取叶子；再加答案考点。
- **完形 / 语法选择**：只写语篇体裁 + 主题，不写语法、不写词汇辨析。
- **阅读 / 任务型 / 读写综合**：语篇体裁 + 主题 + 阅读技能（设题角度）。
- **教材语篇填空 / 短文填空 / 选词填空**：语篇体裁 + 主题 + 词汇 + 语法 + 答案考点。
- **补全对话**：语篇体裁 + 主题 + 语用。
- **单词拼写**：词汇 + 语法 + 语音 + 答案考点。
- **完成句子**：词汇 + 语法 + 答案考点。
- **情景运用 / 翻译**：词汇 + 语法 + 语用。
- **改错**：词汇 + 语法。
- **书面表达**：语篇体裁 + 主题。
- **其他**：按实际材料判语篇体裁、主题；阅读类任务加阅读技能；其余按内容。

## 四、答案考点怎么写

不是独立维度：写该题或该空实际考到的**词汇或语法叶子**。

- 单词拼写：名词→`名词辨析`；动词→`动词辨析`；需变形再加 `名词的数` / `动词的基本形式`；需派生加 `构词法/派生法（前缀、后缀）`。
- 选词填空 / 完成句子：写出该空的搭配或语法点叶子（如 `固定搭配`、`一般过去时`）。
- 一道题可能有多处考点 → 多个叶子并列，仍遵守「同维度只挂一个」的例外：不同维度可并列。

## 四之二、听力其他：三种变体

新表把「听力关键词语选择」单列成行，但**框架里没有这个主类**（固定 26 个），所以按「听力其他」的变体执行：

| 变体 | 判定依据 | 打标 |
| --- | --- | --- |
| 听力关键词语选择 | 题干「选出一个你所听到的单词或短语」、选项为音近词 | 语音/基本读音/字母在单词中的基本读音 + 词汇辨析/<词性> +（答案考点） |
| 情景反应 | 选项是应答语（Have fun. / Never mind.） | 语用/情景交际 |
| 音标辨识 | 题干或选项含 /u/ 这类音标 | 语音/基本读音/字母在单词中的基本读音 |

其余「听力其他」（如听力匹配）按主行打标：语篇体裁 + 主题。

**框架补上「听力关键词语选择」后**，直接把这些题的主类改过去即可，标签不用动。

## 五、多标签原则

1. 一题通常 2–4 个标签，**同一维度最多一个**（主题的一级与叶子视作一个维度的一对）。
2. 组级标签写整段材料（体裁 + 主题）；子题标签写各自考点（阅读技能）。
3. 拿不准就不加，不要凑标签；加了错标签比没加更难查。

## 六、校验

```bash
python scripts/04-knowledge/find_kp.py 推理判断     # 查节点是否存在
python scripts/04-knowledge/check_tags.py --ids AH-2022
python scripts/04-knowledge/fill_subtags.py --ids AH-2022 --list   # 找空子题
```

`check_tags.py` 的判定口径：

| 项 | 含义 | 默认是否失败 |
| --- | --- | --- |
| 空标签 | 没有知识点 | 失败 |
| 非叶子 | 停在父节点（含维度根节点） | 失败 |
| 禁标维度 | 旧规则里的硬禁止（保留兼容） | 失败 |
| 越界维度 | 不在该题型「可考范围」内（对照表派生） | 只报告，`--strict` 才失败 |

「可考范围」来自对照表：例如听力短对话只有 主题、设题角度，打了 `语篇体裁/日常口语` 就是越界；
完形只有 语篇体裁、主题，打了 `阅读技能/句意理解` 也是越界。历史数据按旧规则打过标，
所以默认只报告；新录的题建议用 `--strict` 卡住。
