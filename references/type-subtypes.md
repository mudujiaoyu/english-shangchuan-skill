# 题型子类（建议存储值）检索表

> 来源：`filter-framework.json`（版本 1.0，源自《题库筛选与检索框架1.0.xlsx》D 列「建议存储值」）。
> 26 个主类是**固定目录**，每个主类下的子类同样是**固定目录**：只能选，不能新增/改名/合并。
> 落库位置：`filterMetadata.subtypes`（数组，多选；无子类的题型留空数组）。

## 怎么用

**遇到不标准、拿不准的题**，不要凭主类感觉，按下面三步检索：

1. 先定 26 个主类里的一个（依据大题标题 + 结构特征）；
2. 在主类的子类表里**逐条比对判定线索**，选出唯一（或最多两个）匹配项；
3. 一条都对不上 → 选该主类的「其他」子类（若有）；连「其他」都没有 → **停下报候选与依据**，由人工决定。

子类不是必填装饰，它决定题库筛选能不能命中。**上传时漏写 `subtypes`，这道题在按子类筛选时就会消失。**

## 多选

框架里只有「单词拼写」注明可多选（`note: 设置多选`）。其余题型**一般单选**；
一篇材料确实同时满足两个子类（如阅读既排序又回填）时，选更贴近设问方式的那一个。

## 常见误判

- **听力短对话「选图片」**：只有选项位是空壳 + 配图才算；图片是整篇海报、logo、二维码的不算。
- **阅读理解**：七选五 → `阅读回填`，不是 `选择5题`；给段落选标题 → `阅读匹配`。
- **补全对话**：选项在方框里、有 2 个多余 → `7选5`；要求自己写句子 → `填写句子`。
- **单词拼写**：给首字母 + 汉语 → `汉语及首字母`（不是「汉语提示」）。
- **书面表达**：中文要点 → `列中文要点`；思维导图 → `思维导图`，别都塞进「列中文要点」。
