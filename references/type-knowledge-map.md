## 设题角度分两支（目录 1.1）

- 听力类题型 → `设题角度/听力/`：细节理解、推理判断、人物关系、地点推断、主旨大意
- 阅读类题型（阅读理解、任务型阅读、读写综合）→ `设题角度/阅读/`：22 项，含细节理解、最佳标题、写作手法等

同一个名字在听力和阅读下各有一份，所以**必须带上级**，不能只写「细节理解」。

## 约定

1. 维度名本身不写进标签。
2. 主题写「一级主题 + 最后一级」→ **实际落库只写最后一级叶子**（一级主题是父节点，`check_tags.py` 判非叶子）；
   一级主题只用在交接单说明里。
3. 体裁、词汇、语法、语音写根以下各级；语用只写叶子。
4. 填空、拼写、完成句子、选词类另加「答案考点」＝该空考的词汇或语法叶子。
5. 听力关键词语选择是独立主类（27 类之一），打 语音 + 词汇 + 答案考点。
