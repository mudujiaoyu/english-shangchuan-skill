## 听力其他的三种变体

框架里没有「听力关键词语选择」这个主类（固定 26 个），所以它作为**听力其他的变体**执行：

| 变体 | 判定 | 打标 |
| --- | --- | --- |
| 听力关键词语选择 | 题干含「听到的单词/短语」或选项为音近词 | 语音、词汇、答案考点 |
| 情景反应 | 选项为应答语（Have fun. / Never mind. 等） | 语用 |
| 音标辨识 | 题干或选项含 /u/ 之类音标 | 语音 |

## 约定

1. 维度名本身不写进标签，只写具体子标签。
2. 主题写两个：一级主题 + 最后一级，中间层不写。
3. 语篇体裁、词汇、语法、语音写根以下各级。
4. 语用只写叶子。
5. 阅读类设题角度写阅读技能叶子；听力子项目录暂无分支，先不落标。
6. 填空、拼写、完成句子、选词类另加「答案考点」＝该空考的词汇或语法叶子。
7. 框架未收录「听力关键词语选择」时，按听力其他变体处理，等框架补充后再改主类。
