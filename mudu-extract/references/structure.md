# 结构识别指南（规则不写死）

结构永远从**手上的原卷**推，不从年份、不从卷型推。下面的步骤产出「本卷结构清单」，
后续步骤都对着清单做。已知形态只是参考，任何一处对不上，一律以原卷为准。

## 第一步：切大题

- 找形如 `Ⅰ.` / `一、` / `Part A` / `第一节` 的标题行，记录：序号、标题、题号区间、分值、有无听力。
- 用题号连续性反推：题干行以 `^\s*(\d+)[.．、]` 开头；**题号跳跃处就是大题边界**。
- 没有显式标题的教辅，用「共用材料 + 指令句」判断边界（如「阅读下列短文」「根据对话内容」）。

## 第二步：判定题型（查目录，不靠记忆）

取 `http://127.0.0.1:8089/filter-framework.json` 的 `question_types`（26 主类 + 子类），
对每个大题做「标题关键词 + 结构特征」双重匹配：

| 结构特征 | 指向的子类 |
| --- | --- |
| 每题 3 个选项 / 4 个选项 | 单项填空 / 三个选项、四个选项 |
| 空数 5 / 10 / 15 | 完形填空 / 5空、10空、15空 |
| 每篇 3 / 4 / 5 小问 | 阅读理解 / 选择3题、选择4题、选择5题 |
| 有共用材料或共用选项 | 题组（`unit_kind: "group"`） |
| 题干带限词数要求（不超过 15 个词） | 任务型阅读 / 阅读问答 |
| 首字母 + 汉语提示 | 单词拼写 / 汉语及首字母 |
| 中文要点、词数 80–100 | 书面表达 / 列中文要点 |

输出「主类 + 子类 + 依据」。**匹配不到、或两个以上同等合理 → 暂停问人**，不新增、不改名、不合并题型。

## 第三步：定题组与媒体

- **题组信号**：「听下面一段对话，回答第 16 至 17 小题」「阅读下列短文」「从方框内的选项中选出…」
  「你将听到一篇短文」——共用材料/共用选项/多小问，满足任一即题组。
- 组级 `material` 放共用文字；表格类（信息转换、海报、时间表）必须同时给 `materialBlocks`。
- **图片题识别**：选项位置只有 `A.` `B.` `C.` 空壳、没有文字。选项图张数 = 图片题数 × 选项数，
  按文档顺序取，起点要肉眼确认（前面的 logo / 二维码 / 整篇海报都不算）。
- **音频**：段数 = 听力单元数（不是题数）；有试音先切掉。

## 输出：本卷结构清单

```
大题 | 题号区间 | 题数 | 主类/子类 | 单题 or 题组 | 媒体（图/音频）
```

先落这份清单，再写批次。清单错了后面全错，所以这一步值得慢。

## 已知形态（样例，仅供参考，不作判据）

| 类型 | 典型形态 | 注意 |
| --- | --- | --- |
| 中考真题 / 模拟卷（安徽 2010–2019） | 四大块：听力 5 大题 19 单元、单项 15–20、完形两篇、补全对话、阅读 4 篇 + 任务型、拼写 + 书面表达；95–100 编号题 | 题号区间每年挪动，按清单走 |
| 改制后（2020 起） | 听力 4 大题、单项 10 题、80 编号题 | 听力段间夹中文题头，切分要用显式终点 |
| 同步练习 / 课时作业 | 按课时或单元切，常无听力；题型偏词汇语法、补全对话、短文填空 | 一册可能多套，逐套成批 |
| 月考 / 期中期末 | 题量介于单元卷与真题之间，可能无听力 | `source_type` 填月考试题 / 期末试题 |

## 结构变了怎么办

**不改判定规则**，只在「已知形态」里补一行样例。三步识别逻辑对任何卷型都适用。
